# Ayurvedic Wellness App

A **React.js** based Ayurvedic wellness application that helps users track their **Prakriti**, get **diet suggestions**, **daily routines**, and **follow-ups**.  
All data is stored **locally in the browser (localStorage)**, so no backend or database is required.

---

## 🌿 Features

1. **User Profile**  
   - Enter personal details (name, age, gender, health info)  
   - Data saved in localStorage  

2. **Prakriti Analysis**  
   - Questionnaire-based or AI-inspired analysis  
   - Determines user's **Vata, Pitta, or Kapha** type  

3. **Diet Chart**  
   - Personalized diet recommendations based on Prakriti  

4. **Daily Schedule**  
   - Routine suggestions (wake-up time, exercise, meditation, meals)  

5. **Follow-ups**  
   - Track progress, reminders, and notes
